# Данные соревнования

Источник: [Kaggle](https://www.kaggle.com/t/1918f3f6435300327d38d6c596f97394).

Все три файла сохранены в gzip без потери данных: `train.csv.gz`, `test.csv.gz`
и `sample_submition.csv.gz`. Producer читает архивы напрямую; распаковка не нужна.
Исходные несжатые CSV исключены из Git, чтобы не дублировать данные и не превышать
лимит GitHub на размер отдельного файла.

`checksums.json` содержит размер и SHA256 исходных CSV. После сжатия проверено,
что распакованные байты полностью совпадают с оригиналами.
Для получения обычных CSV на Linux/macOS: `gzip -dk *.csv.gz`.
